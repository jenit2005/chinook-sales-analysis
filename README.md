# Chinook Sales Analysis (SQL)

## What this project does
Analyzes a music store database using SQL to answer business questions.

## Tools used
SQL (SQLite), Python, pandas, matplotlib

## SQL concepts used
JOINs (up to 3 tables), GROUP BY, HAVING, subqueries, date functions

## Key findings
1. Top customer: __Helena Holý__(spent $49.62)
2. Top genre by revenue: __Rock__ ($826.65)
3. Highest revenue month: 2010-01
4. 22 out of 59 customers customers spent more than the average
5. Top country by revenue: __USA__

## Dataset
Chinook sample database
